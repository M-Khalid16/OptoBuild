# ADR-0014: Split-step Fourier solver for the NLSE

* Status: Accepted
* Date: 2026-09-27

## Context
Phase 4 adds nonlinear fiber propagation. Choices: equation/sign convention,
splitting scheme, step control, diagnostics, and how the solver relates to
the existing exact linear fiber.

## Decision
1. **Equation (our convention, ADR-0002):**
   `∂A/∂z = −α/2·A − i(β2/2·ω² + β3/6·ω³)A − iγ|A|²A`. Relative to Agrawal the
   sign of `i` is flipped (carrier `e^{+iω0t}`); validated against the
   complex conjugate of Agrawal's closed-form N = 2 soliton and a physical
   SPM check (red-shifted leading edge).
2. **Symmetric (Strang) splitting**, global error O(h²):
   `D(h/2) · N(h) · D(h/2)`, with `D` the exact dispersion operator
   (`physics.fiber.fiber_transfer_function`, α = 0) and `N` the **exact**
   Kerr+loss step `A e^{−αh/2} exp(−iγ|A|²L_eff(h))`
   (`physics.nonlinear.kerr_loss_step`). Consequences: γ = 0 reproduces the
   linear fiber exactly; pure SPM with loss is exact for any step.
3. **Step control:** adaptive nonlinear-phase criterion (peak phase per step
   ≤ `max_phase`, default 5 mrad; step ≤ `max_step`) re-evaluated each step
   (Sinkin et al., JLT 21, 61 (2003)), or a fixed number of steps.
   Local-error (step-doubling) control and RK4IP are deferred until needed.
4. **Diagnostics:** per-step phase (fixed mode > 0.05 rad → warning), spectral
   truncation (energy in the outer 10 % of the band), window wrap-around for
   pulse-like inputs, non-finite fields → `NumericalStabilityError`.
   Records `n_steps`, max step phase, nonlinear-phase bound `γP_peak L_eff`.
5. **Scope:** scalar field, instantaneous Kerr (SPM). Raman response,
   self-steepening, XPM between polarizations/channels and PMD are Phase 9 /
   later; they will extend `N` without changing the splitting framework.

## Alternatives considered
* *RK4IP*: 4th order, but costlier per step and the O(h²) split step is
  standard for telecom propagation; can be added behind the same interface.
* *Loss inside the linear operator*: then pure SPM is only O(h²) accurate;
  the exact Kerr+loss step is simpler to validate.

## Consequences
* One place (`solvers.ssfm`) for nonlinear propagation; components stay thin.
* Validation tests pin the sign convention, order of accuracy and invariants.
